# 🖤 DE NOIR – Premium Streetwear eCommerce Platform

DE NOIR is a modern fashion eCommerce platform designed to deliver a bold, minimal, and luxury online shopping experience. Built with a sleek dark aesthetic, DE NOIR represents premium streetwear culture blended with modern web technology.

## 🚀 About The Project

DE NOIR is an online clothing store where users can browse products, explore collections, and shop premium apparel with a smooth and responsive interface.

This project was bootstrapped with [Create React App](https://github.com/facebook/create-react-app) and focuses on performance, clean UI design, and scalability.

## ✨ Features

- 🖤 Dark luxury themed design
- 🛍️ Product listing & categories
- 🔍 Search functionality
- 🛒 Add to cart system
- 👤 User authentication (Login / Register)
- 📱 Fully responsive (Mobile + Desktop)
- ⚡ Optimized production build

## 📦 Installation & Setup

Clone the repository:

```bash
git clone https://github.com/yourusername/denoir-web.git
cd denoir-web
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm start
```

Open your browser and visit:

```
http://localhost:3000
```

## 🏗 Build for Production

To create an optimized production build:

```bash
npm run build
```

The build files will be generated inside the `build/` folder.
